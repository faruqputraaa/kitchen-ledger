# Ktichen Ledger

Kitchen Ledger adalah aplikasi berbasis MERN Stack yang membantu pengguna mengelola resep masakan, inventory bahan, food cost, histori harga, pembelian, dan analisis pengeluaran.

Target pengguna:

- UMKM
- Restoran
- Cafe
- Catering
- Home Industry

Tujuan utama:

- Menghitung food cost otomatis
- Menyimpan resep
- Mengelola stok
- Mengelola pembelian
- Menganalisis keuntungan
